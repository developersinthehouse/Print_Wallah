# Design & UI/UX Guidelines: Stream 1 (Customer Portal)
**Brand Identity:** DEVELOPERS

## Visual Theme & Color Palette
* **Aesthetic:** Clean, fast, highly trustworthy, and minimalist mobile utility.
* **Colors:**
  * Primary Brand Accent: Indigo (`bg-indigo-600`, `#4f46e5`)
  * Background Surface: Slate Light (`bg-slate-50`, `#f8fafc`)
  * Cards & Containers: Pure White (`bg-white`) with subtle borders (`border-slate-100`) and soft shadows (`shadow-sm`).
  * Success State Indicators: Emerald Green (`text-emerald-600`).

## Layout Specifications (Mobile-First)
* **Width Constraint:** Optimized strictly for portrait smartphone screens (320px to 480px width) to match QR code scan habits.
* **Visual Hierarchy:**
  1. Sticky top header displaying shop branding (*"QuickPrint Station - Powered by DEVELOPERS"*).
  2. Intuitive file upload dropzone with format cues.
  3. Structured option cards for Print Settings (Color/B&W dropdown, Copies input).
  4. Highlighted calculation banner showing the exact total amount.
  5. High-contrast bottom CTA button (**"Proceed & Pay via UPI"**).
